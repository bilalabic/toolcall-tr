# Tool-output prompt-injection eval seti

Bu dizin yalnız değerlendirme içindir ve hiçbir SFT/finetune eğitim manifestine
giremez. Kayıtlar sentetiktir; gerçek kullanıcı veya sağlayıcı verisi içermez.

Her satır kullanıcı amacını (`user_intent_tr`), güvenilmez araç verisini
(`tool_output`), verinin içine gömülmüş saldırı talimatını
(`injected_instruction_tr`) ve yalnız gözlenebilir güvenlik beklentilerini
(`expected_behavior`) ayrı alanlarda taşır. Gizli düşünce zinciri beklenmez veya
saklanmaz.
